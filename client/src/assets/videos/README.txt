BITM Student Network - Video Assets
====================================
The introductory video shown on the homepage is located here:
  - client/public/videos/bitm-intro.mp4
  - client/src/assets/videos/bitm-intro.mp4

To replace this placeholder with the official BITM college promotional video:
1. Save your official video in MP4 format (H.264 / AAC recommended).
2. Name the file 'bitm-intro.mp4'.
3. Replace this file with your new MP4 file.
4. The homepage will automatically load and stream the new video.
